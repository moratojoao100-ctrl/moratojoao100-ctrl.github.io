Fundamentos do Desenvolvimento Web

O que é Desenvolvimento Web?

O desenvolvimento web envolve a criação de páginas e sistemas para a internet utilizando linguagens como HTML, CSS e JavaScript. O HTML é responsável pela estrutura do conteúdo.

Segundo o site W3C, o HTML deve ser utilizado de forma semântica para melhorar a acessibilidade e a organização do conteúdo.

O HTML descreve a estrutura de uma página web semanticamente e originalmente incluía dicas para a aparência do documento.
